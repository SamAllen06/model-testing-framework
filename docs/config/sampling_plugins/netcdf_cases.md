# NetCDF Cases
APP/config/sampling_plugins/netcdf_cases.ini

## Purpose
Configures the [NetCDF Cases sampling plugin](../../src/sampling_plugins/netcdf_cases/netcdf_cases.md)

## Fields
All paths are relative to [APP_ROOT](../../src/root.md).

| Field Name      | Type | Description                                                                                   |
|-----------------|:----:|-----------------------------------------------------------------------------------------------|
| group_directory | Path | Path to the directory containing the NetCDF files storing the constant values for the samples |
