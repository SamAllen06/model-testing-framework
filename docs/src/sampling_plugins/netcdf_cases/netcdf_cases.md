# NetCDF Cases
APP/src/sampling_plugins/netcdf_cases/

## Purpose
NetCDF Cases is a sampling plugin that uses NetCDF files to generate
[SampleGroup](../../sampling/sample_group.md)s. 

## Functionality
NetCDF Cases uses NetCDF files, which contain data for all the Samples to include in the
SampleGroup. 

Each NetCDF file will become its own SampleGroup.
